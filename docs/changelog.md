# Changelog

Все изменения в проекте Life ERP.

## [Unreleased] - В работе
- Логика "Умного списка" (фильтрация по min_threshold)
- Разделение на вкладки (Tabs) в интерфейсе

## [0.2.0] - 2026-02-02
### Added
- Полный редизайн интерфейса на Material UI (MUI).
- Адаптивность для мобильных устройств.
- Отображение карточек с тенями и иконками.

## [0.1.0] - 2026-02-01
### Added
- Инициализация проекта (React + Vite).
- Настройка Supabase и подключение БД.
- CI/CD пайплайн для GitHub Pages.
## [0.3.0] - 2026-02-03
### Added
- **Smart Shopping List:** Логика автоматического добавления товаров в список покупок.
- **Tabs UI:** Разделение экрана на вкладки "Склад" и "Купить".
- **Threshold Control:** Возможность менять минимальный порог (min_threshold) прямо в карточке товара.
- **Badge:** Красный счетчик товаров, которые нужно купить, на иконке корзины.
## [0.4.0] - 2026-02-03
### Added
- **Shops Integration:** Создана таблица магазинов и связь с товарами.
- **Grouped Shopping List:** Список покупок теперь разбит на секции по магазинам (Рынок, Супермаркет и т.д.).
- **Item Settings:** Возможность привязать товар к конкретному магазину прямо в карточке.

### Changed
- **Data Philosophy:** Принят стандарт "Один товар — Одна карточка". Поле магазина используется как "Предпочтительное место покупки".

## [0.5.0] - 2026-02-06
### Added
- **AI Integration:** Подключен Google Gemini API.
- **Magic Input:** Единая строка ввода для всех типов данных (продукты, спорт, мысли).
- **Activities & Journal:** Добавлены таблицы для трекинга привычек и ведения дневника.
- **Prompt System:** Логика AI вынесена в отдельный модуль `prompts.js`.

### Changed
- **UI Structure:** Добавлен фиксированный футер с полем ввода команд.
## [0.5.1] - 2026-02-06
### Changed
- **AI Logic Upgrade:** Обновлен `prompts.js`. Добавлен математический алгоритм расчета времени тренировки на основе количества повторений.
- **Data Parsing:** Реализован "Спортивный шифр". AI теперь автоматически разбивает строку цифр (543222) на подходы для правой и левой руки.
